# Super Homem Portugal

Cria uma landing page de alta conversão para vender em Portugal o suplemento alimentar masculino “Super Homem”, da PlantaNatur, através do modelo Cash on Delivery (COD).

IMPORTANTE:

- A página deve ser escrita em PORTUGUÊS DE PORTUGAL (PT-PT), não português do Brasil.

- Vou anexar a imagem real do produto no Lovable. Usa essa imagem como imagem principal do produto e NÃO cries uma embalagem fictícia.

- Não alteres o nome, embalagem, rótulo ou aparência do produto.

- O objetivo principal da página é levar o visitante a clicar no botão de compra e ir para o checkout.

- Não colocar  opções de quantidade na landing page, porque a escolha da quantidade será feita no checkout.

- Não criar sistema de pagamento próprio.

- O checkout externo é:

https://link.conblue.app/pngwi

DESIGN:

- Design premium, masculino e moderno.

- Aparência de produto de saúde/bem-estar, mas sem parecer uma página médica.

- Usar bastante espaço em branco.

- Tipografia forte e fácil de ler.

- Criar excelente contraste entre títulos, textos e CTAs.

- O produto deve ser o protagonista visual.

- Usar elementos visuais relacionados com vitalidade, energia, confiança e bem-estar masculino, sem imagens sexualmente explícitas.

- Evitar exageros visuais.

- Página totalmente responsiva para telemóveis, porque a maioria do tráfego virá de anúncios mobile.

- Botões grandes e fáceis de clicar.

- Considerar um botão CTA fixo no fundo do ecrã em mobile:
